# backend-ledger – Claude Instructions

## README.md rules (user ne bola hai, hamesha follow karna)

`readme.md` is project ki step-by-step diary hai. Isko padhke hi samajh aana chahiye ki project me kya-kya aur kaise-kaise kiya gaya.

- User jab bhi koi kaam kare/karwaye (feature, setup, package install, fix, etc.), readme.md me uski entry add karo. Puraana content mat hatao, sirf update/append karo.
- **Jab bhi user commit kare**, usse pehle readme.md update karo: is commit me kya-kya naya hua likho.
- Style: thoda detail me, lekin **crisp**. Bookish/formal language nahi. Simple Hinglish/English, chhote points.
- Jahan zaroori ho, beech-beech me **code snippet** daalo (chhota aur relevant) taaki "kaise kiya" clear ho.
- Structure: step-by-step (Step 1, Step 2...) ya commit-wise sections, jo bhi clean lage. Har step me: kya kiya, kyu kiya, aur kaise (command/code).
- Naye packages/commands/folder structure ka mention zaroor karo.

## Project info

- Node.js + Express (v5) backend, CommonJS (`"type": "commonjs"`).
- Entry: `index.js` (package.json ke hisaab se).
